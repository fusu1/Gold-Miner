# 黄金矿工

使用 Phaser 3、TypeScript 和 Vite 制作的单人 2D 网页游戏。

**在线游玩：https://fusu1.github.io/Gold-Miner/**

## 玩法

- 关卡模式：5 个关卡，在倒计时内达到目标金额，关间可购买炸药与力量药水。
- 无尽模式：持续采集增加时间，清空矿洞后进入下一波。
- 黄金、石头、钻石有不同价值和重量，重量会影响回收速度。
- 问号袋：75% 概率获得 50、100、150 或 300 金币，25% 概率获得一枚炸药；库存满时折合 100 金币。
- 经典 2D 矿工、矿洞和矿物贴图，包含拉动和爆炸动画、循环背景音乐及操作音效。

## 操作

| 操作 | 电脑 | 手机 / 平板 |
| --- | --- | --- |
| 发射钩子 | ↓ 或 Space | 点「出钩」 |
| 销毁正在拖拽的物品 | ↑ | 点「炸药」 |
| 暂停 / 继续 | Esc | 点「暂停」后选择继续 |
| 重新开始 | R 或暂停菜单 | 暂停菜单 |

手机支持横竖屏，按钮位于矿洞下方。切换标签页或窗口失焦时自动冻结计时和模拟，返回后继续。游戏进度不会在刷新后保留。

首次点击或按键后启用音频。设置中可分别关闭背景音乐与音效，偏好会保存在当前浏览器；暂停和切换标签页时停止播放，继续后音乐从原位置恢复。音频加载失败不会阻止游戏运行。素材来源及 CC0 许可见 [AUDIO_CREDITS.md](AUDIO_CREDITS.md)。

## 本地运行

需要 Node.js 22.12+ 或 24+，建议使用 Node.js 24。

```sh
npm ci
npm run dev
```

打开终端显示的地址。Windows 也可双击 `启动游戏.bat`，游玩时保持启动窗口打开。不要直接双击 `index.html`。

```sh
npm run typecheck   # TypeScript 检查
npm run build       # 生成 dist/
npm run preview     # 本地预览构建结果
```

## 自动发布

GitHub Pages 的 Source 设为 **GitHub Actions**。推送到 `main` 后，工作流自动安装依赖、检查类型、构建并发布。

工作流为部署设置 `/Gold-Miner/` 资源前缀。本地开发仍使用根路径；如果更改仓库名称，需要同步修改 `.github/workflows/deploy.yml` 中的前缀。

## 目录

- `src/app/`：界面状态和设置。
- `src/audio/`：音频播放、浏览器交互解锁和游戏状态音效映射。
- `src/content/`：物品、关卡、无尽布局和问号袋奖励配置。
- `src/game/`：钩子运动、连续碰撞、固定时间步和挑战规则。
- `src/input/`：键盘输入。
- `src/view/`：素材加载、画面和动画。
- `src/ui/`：中文菜单、商店、暂停和触屏按钮。
- `public/assets/`：游戏运行所需图片。

运动和奖励逻辑使用纯 TypeScript，与绘制及输入分离。调整手感看 `src/game/config.ts`，调整金币、重量及奖励看 `src/content/`，调整素材布局看 `src/view/ClassicAssets.ts`。

仓库仅包含运行和构建所需内容；本地测试文件、截图、生成记录、素材预览页、未使用素材、依赖目录及构建输出均由 `.gitignore` 排除。
